Against 2024, it is the trained version of Turiya's prompted whole-map LLM (30.75 ARI): supervision, a grammar and thresholds close most of the gap, but on dev a mid-size LLM still trails the encoder. |

| A4 · Discussion | [`A4-discussion.md`](A4-discussion.md) | How a decision model does at argument mining. It reads each question literally, so it is the best of the four at finding support (neighbour recall 0.51) and its direction (87%, no reasoning), and finds the most Conflicts. It is the worst at the annotators' conventions: it calls restatements support, and a worked example doesn't help. Asking each relation two ways (per pair, and per proposition with competing targets) is the main lever. |

**Conventions for new reports**
- Name them `NN-short-name.md` for shared phases. Each approach gets one report (`A1-cross-encoder.md`, …), with a section added per phase.
- Use this shape: at a glance → method → results → lessons for other approaches → open items → how to reproduce.
- Every number must come from a committed file under `results/` (or `eda/`), named in the report's header.
- Comparisons with 2024 are only fair on the 11 test maps; label dev-versus-test numbers as references.
